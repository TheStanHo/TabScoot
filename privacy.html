Tab Scoot — Privacy policy

Aligns with the Chrome Web Store User Data FAQ and Limited Use expectations. Keep this page consistent with your store listing and the extension’s behavior.

1. Do we handle personal or sensitive user data?

Yes, in Chrome’s sense, but only on your device and only for tab-management features.

Tab Scoot reads and may store locally information that Chrome classifies as sensitive in broad categories—for example web browsing activity in the form of page URLs and titles for tabs you interact with (open tabs, set-aside stash, saved groups). It does not scrape full page body text, screenshots, or form fields from websites for upload to the developer.

Because Tab Scoot handles such data, this policy describes collection, use, and sharing as the User Data FAQ expects.

2. What information do we collect?

Per the User Data FAQ, we explain information the extension collects—including via permissions and storage—not only what you type in a form.

Source Data Notes
chrome.tabs Tab URLs, titles, ids, window membership, discarded state Popup, set-aside, saved groups, optional discard, command palette. Not sent to servers operated by this project.
chrome.storage.local Set-aside stash and saved groups: URLs and titles (and names you choose for groups), plus preferences (e.g. auto-suspend on/off, idle minutes) Persists until you delete items, restore stash, or remove the extension / clear storage.
chrome.sessions Chrome’s recently closed entries (session ids, titles, urls as exposed by the API) Shown in the popup; not copied into a separate cloud database by this project.
Content script (palette) Injects UI into normal http/https pages Does not read or upload the host page’s article text, images, or media; adds extension UI and talks to the extension runtime.
Palette search Your search string processed inside the extension Includes bundled local search (e.g. fuse.js). Not sent to any server operated by this project.
chrome.alarms Alarm name / schedule only (no tab contents) Used only when optional auto-suspend is on, to wake the service worker on a fixed interval and evaluate discard. Cleared when suspend is off.
activeTab + scripting One-time script injection on the focused tab when needed Lets the command palette load on normal http/https pages after a keyboard shortcut, including a fallback inject if the page has not picked up the content script yet. Same bundled palette code as the manifest content script — not remote code.

We do not collect, as part of the shipped extension: health data, payment card data, passwords, your email for login (there is no account), general email/chat contents, GPS location, or a separate log of every click/keystroke across the web.

Automatically collected data: No extension-owned analytics endpoints, telemetry beacons, or remote logging servers in the shipped product. No server-side HTTP logs from this project for your browsing from routine extension use.

Identifiers: No cloud user id from the developer. Chrome assigns an extension id and uses local storage keys as part of normal browser behavior.

3. How do we use the information?

We use the data only for tab and window management you trigger in the UI or via shortcuts:

  • Set-aside (“only this tab”) and restore
  • Save and reopen named tab groups
  • Recently closed list and restore
  • Command palette (search / switch tabs and groups)
  • Optional background tab discard (memory saver) when you enable it

Not implemented: personalized ads, retargeting, credit scoring, selling browsing history, or routine human reading of your tab list on a developer server.

4. What information do we share, and with whom?

We do not sell, rent, or trade your data. We do not transfer URLs/titles/stash contents to servers operated by this project—this build has no project-operated backend for extension data.

Third parties:

  • Google / Chrome: The store and browser are governed by Google’s policies. See Google Privacy Policy.
  • Websites you visit: Normal web requests are between you and the site, not an upload to the Tab Scoot developer.

Transfers for mergers, security, or legal process would only apply if a future publisher policy says so.

5. Security (handling requirements)

Sensitive data (tab URLs/titles, stash, groups) stays in Chrome local extension storage and extension contexts. It is not transmitted to the developer’s servers by the extension in this product design.

HTTPS between you and websites is unchanged. Use a current Chrome version, lock your device, and review chrome://extensions on shared computers.

6. Retention and your control

  • Saved groups and stash: Until you delete them, restore the stash, or uninstall / clear extension data.
  • Preferences: Until you change them or clear storage.
  • Recently closed: From Chrome’s session data; retention follows Chrome’s rules.

Access / erasure: Use the popup; advanced users may inspect extension storage in developer tools. Uninstalling removes extension storage for that profile (subject to Chrome behavior).

7. Limited use of user data (Chrome Web Store)

  1. Allowed use — Data from permissions is used only to provide the extension’s single purpose: helping you manage tabs and saved groups (including optional discard).
  2. Allowed transfer — No routine transfer to the developer’s servers for unrelated purposes in this build.
  3. Prohibited advertising — We do not use or transfer user data for personalized, re-targeted, or interest-based advertising.
  4. Prohibited human interaction — We do not allow humans to read your tab data for routine operations.

See: Limited Use policy.

8. Prominent disclosure and consent (when it applies)

Some sensitive uses require in-product disclosure before collection. For Tab Scoot, tab URLs/titles for stash, groups, and the palette are closely related to the described tab-management purpose and UI. This policy supplements the store listing and in-extension descriptions.

9. GDPR (EU) — plain-language note

Informational only, not legal advice.

10. Changes

If Tab Scoot gains analytics, cloud sync, accounts, or remote code, update this page, the Chrome Web Store disclosures, and the extension so they stay consistent.

Revise the policy text when you publish meaningful product or data-practice changes.
